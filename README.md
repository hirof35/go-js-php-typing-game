# 3層連携 5問タイピングゲーム (Time Limit Edition)

フロントエンド、API仲介層、バックエンド（データ・判定処理）をそれぞれ異なる言語で実装した、Web API連携の学習に最適な3層構造のタイピングゲームです。

## 🏗️ システム構造とデータの流れ

本プロジェクトは以下の3つの要素が連携して動作します。

1. **フロントエンド (HTML / JavaScript)**: 画面描画、キー入力判定、制限時間タイマー（30秒）
2. **仲介API層 (PHP - Apache ポート: 80)**: CORS制御、フロントからのリクエストをGoへ仲介（読み込み）
3. **バックエンド (Go言語 - ポート: 8081)**: お題データの提供、スコアに応じたメッセージ判定

### データのバケツリレー
* **お題取得**: `JS` ➔ `PHP` ➔ `Go (JSON提供)` ➔ `PHP (転送)` ➔ `JS (画面表示)`
* **スコア送信**: `JS` ➔ `PHP` ➔ `Go (評価判定)` ➔ `PHP (転送)` ➔ `JS (クリア表示)`

## 📂 フォルダ配置構成

XAMPPの公開ディレクトリ（`htdocs`）配下に以下のようにファイルを配置します。

```text
C:\xampp\htdocs\typing-game\
  ├── game.html    (フロントエンド画面・タイマー処理)
  ├── index.php    (API仲介・cURL通信処理)
  └── main.go      (Go言語 APIサーバー)
🚀 起動・プレイ手順
1. PHP（Apache）の起動
XAMPP Control Panel を起動します。

Apache モジュールの横にある 「Start」 ボタンをクリックし、緑色（Running）の状態にします。

注意: 別のアプリがポート80番を占有していないか確認してください。

2. Go言語サーバーの起動
PowerShell または ターミナルを開きます。

プロジェクトのディレクトリに移動し、以下のコマンドを実行します。

Bash
cd C:\xampp\htdocs\typing-game
go run main.go
ターミナルに Go API Server running on http://localhost:8081 と表示されれば準備完了です。（この画面は閉じずに開いたままにしてください）

3. ゲームのプレイ
ブラウザ（Chromeなど）を開きます。

アドレスバーに以下のURLを入力してアクセスします。
👉 http://localhost/typing-game/game.html

「ゲームスタート」を押すと、30秒のカウントダウンと共にゲームが始まります。

🎮 ゲームルールと仕様
出題数: 全5問

制限時間: 30秒

ゲームオーバー: 30秒以内に5問すべてを入力できなかった場合、その場でタイムアップとなり「リトライ」を促します。

ゲームクリア: 30秒以内に全問正解するとタイマーがストップし、確定したクリアタイムがGoサーバーに送信され、タイムに応じたお祝いコメント（判定結果）が返ってきます。

💡 技術的なトピック（このプロジェクトで学べること）
CORS (クロスオリジンリソース共有) の回避: 異なるポート・ドメイン間での安全な通信のためのヘッダー制御（PHP側で実装）。

PHPによる外部API呼び出し: file_get_contents や cURL を使った、別サーバー（Go）からのJSONデータの読み込みと転送。

JavaScriptによる非同期処理: fetch と async/await を用いた、画面をリロードしないAPI通信（SPAの基本構造）。

Go言語の標準httpパッケージ: 外部フレームワークを使わない、軽量で高速なREST APIサーバーの構築。

非同期タイマー処理: setInterval を使った、画面描画を邪魔しないカウントダウンと状態変化の制御。
